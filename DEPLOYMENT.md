# Deployment setup

GitHub source: `ceoYS/YS` (main).
Vercel project: `wethru-links` (ceoys-projects).
Production alias: `https://wethru-links.vercel.app/`.
Target custom domain: `https://links.wethru.com/`.

The custom domain is registered in Vercel, but DNS at Spaceship needs a `links` CNAME to the target shown by Vercel. Do not modify the apex `wethru.com` or other subdomain records.

`Studio` and `창업 기록` are placeholders until destinations are confirmed.
